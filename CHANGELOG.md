# Changelog

## 0.2.0

- `api_key` argument (or the `NAMEDAEMON_API_KEY` environment variable): sends a Pro+ or Business API key as `X-ND-API-Key`, so calls use that key's own allowance instead of the per-address limit. Without a key nothing changes.

## 0.1.1

- README: link to the developer page (https://namedaemon.com/developers/). No code changes.

## 0.1.0

- First release: `NameDaemon` client and `namedaemon` CLI for the public NameDaemon REST layer.
